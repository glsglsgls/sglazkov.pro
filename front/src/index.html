Обо мне:

Я — backend-разработчик с 6-летним опытом. Начинал инженером: мои машины автоматизированно строят тоннели по всему миру. Теперь мой код гоняет события по Kafka, крутит ML-модели в Kubernetes и принимает платежи. Python — основной язык, SQL — чёрный пояс.

Первые полтора года — Polymatica ML: платформа для создания и управления ML-моделями. Заменил скучный pandas на распределённые вычисления Dask, написал с нуля сервис здоровья платформы, спроектировал систему лицензирования на RSA и планировщик задач. Внедряли решение у крупных заказчиков.

Затем три года в AXENIX — low-code аналитическая и ML-платформа для банков, ритейла и не только. Входил в топ-2 разработчиков бэкенда в команде из 25 человек. С нуля спроектировал и вывел в прод движок исполнения ML-моделей: батч-, онлайн-, evaluation- и SOAP-скоринг в Kubernetes. Построил с нуля модуль организации дегустационных испытаний — генерация слепых кодов, дизайн экспериментов, экспорт отчётов. Придумал механизм сравнения моделей, позже догрузился DevOps: Helm, CI/CD, Keycloak.

Сейчас — ИТ-экосистема аэропорта Шереметьево (SVO): сервисы отображения рейсов и экранов (FIDS), интеграция аэропортовых систем через Kafka и Postgres. Веду собственную ветку интеграции с аэропортом Пулково — переписал слой данных полётов с raw-SQL на ORM, тюнил пулы соединений, выпускаю релизы в бой.

Параллельно делаю собственные продукты: подписочный сервис с реальными платежами (Keycloak + Yookassa), бэкенд с offline-first синхронизацией, мобильные приложения на Kotlin — всё с Docker и CI/CD. Обожаю технические книги, изучаю технологии в основном только по ним: сейчас исследую asyncio и внутренности Postgres.

Помимо работы я играю в большой теннис, увлекаюсь картингом, коллекционирую музыкальные инструменты и люблю собирать Lego. Неплохо знаю 2 иностранных языка.
